## Цель
Закрепить базовый Kotlin, освоить null-безопасность, функции коллекций и основы корутин, решив набор задач на Kotlin/JVM.

## Выполненная работа
1. Создан Gradle-проект Kotlin/JVM с JDK 17.
2. Реализованы приветствие, определение сезона и хвостовая рекурсия для факториала.
3. Реализованы безопасный разбор строки и обработка списка nullable-чисел.
4. Реализованы средний возраст, группировка слов по первой букве и поиск самого длинного слова.
5. Реализованы suspend-функция с задержкой и три конкурентные задачи с возвратом результатов по порядку завершения.
6. Реализовано дополнительное задание: числовой ввод анализируется на сумму, среднее, количество и сортировку; текст — на число слов, самое длинное слово и количество непробельных символов.
7. Для объектов и функций добавлены KDoc-комментарии и примеры.
8. В main добавлены проверки обычных и граничных случаев.
9. Команда gradlew.bat clean build run --console=plain завершилась с BUILD SUCCESSFUL; выполнены все 24/24 проверки в main. Отдельных файлов для Gradle test нет, поэтому задача test имеет статус NO-SOURCE.

## Среда и запуск
Проект собирается Gradle Wrapper и запускается командой gradlew.bat run на Windows либо ./gradlew run на Linux/macOS. Для выполнения использована доступная Windows-среда с JDK 17; для сборки Kotlin/JVM установка Debian не требовалась.

## Сложности и решения
- Получение результатов в порядке завершения корутин. Последовательный await в порядке объявления не гарантирует порядок фактического завершения. Использован select с Deferred.onAwait; выбранный результат считывается через await.
- Переполнение Long при факториале. Использован Math.multiplyExact, поэтому переполнение обнаруживается вместо выдачи неверного числа.
- Пустые элементы при группировке. Пустые строки пропускаются, потому что у них нет первой буквы.

## Вывод
Решения оформлены в отдельных функциях и объектах, снабжены документацией и проверяются при запуске. Дополнительная функция обрабатывает числовой список, произвольный текст, пустую строку и null.
