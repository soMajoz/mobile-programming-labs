## Цель работы

Освоить Retrofit, JSON-сериализацию и асинхронные запросы, а также связать сетевой источник данных с локальным кешем Room.

## Реализация

Созданы `TaskDTO`, `ApiService` и `RetrofitClient` с Retrofit 2.11.0, OkHttp logging interceptor и конвертером `kotlinx.serialization`. Репозиторий получает постраничные записи JSONPlaceholder, преобразует DTO в сущности и сохраняет их в Room по уникальному `remoteId`. ViewModel объединяет наблюдаемое содержимое Room с состояниями загрузки, пагинации и ошибок. Экран поддерживает обновление, повтор запроса из Snackbar, поиск, сортировку и локальные CRUD-операции.

## Ограничение демонстрационного API

JSONPlaceholder возвращает тестовые данные и не сохраняет изменения, отправленные через POST/DELETE. Поэтому загрузка идёт через GET, а добавление, редактирование и удаление задач выполняются в локальной базе Room.

## Вывод

Room остаётся источником данных для интерфейса: он сразу показывает сохранённые записи и обновляет список после загрузки новых страниц. Сетевые ошибки не блокируют чтение кеша.
