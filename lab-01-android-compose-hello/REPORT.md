## Возникшие сложности и решения
- **Gradle не принимал путь проекта с кириллическими символами.** В `gradle.properties` включено свойство `android.overridePathCheck=true`; после этого сборка прошла.
- **В SDK отсутствовал образ эмулятора API 35.** После принятия лицензий SDK был установлен образ Google APIs x86_64 и создан AVD Pixel 6.

## Новые знания
- Compose описывает интерфейс Kotlin-функциями с аннотацией `@Composable`.
- `Modifier` задаёт расположение и оформление элементов; `@Preview` позволяет просматривать Compose UI в Android Studio.
- Compose-проект хранит разметку интерфейса в Kotlin вместо отдельных XML layout-файлов.
- Android-приложение собирается Gradle, а параметры платформы и зависимости задаются в Gradle-файлах.
