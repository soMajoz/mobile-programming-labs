## Цель

Создать список задач на HTML, CSS и JavaScript, добавить PWA-манифест и Service Worker, проверить автономную работу и собрать Android-оболочку с Capacitor.

## Выполненные работы

1. Использован выданный шаблон Model/View/Controller: TaskModel, TaskView и TaskController.
2. Реализованы добавление, завершение и удаление задач, фильтры, счётчики и адаптивный интерфейс.
3. Список сохраняется в localStorage.
4. Создан manifest.json с именем, областью запуска, цветами и двумя maskable PNG-иконками.
5. Service Worker кеширует оболочку приложения, отдаёт её при отсутствии сервера и удаляет старые кеши при смене версии.
6. Добавлена конфигурация Capacitor и Android-платформа.
7. Создан отдельный файл сравнения PWA, гибридной оболочки и нативного приложения из предыдущих работ.

## Исправления шаблона

- В шаблоне обработчики задачи вызывались через onToggle и onDelete как методы, хотя callback хранились в других полях. Исправлены вызовы callback.
- Обновление счётчика ранее записывало текст непосредственно в контейнер списка и удаляло отображённые задачи. Счётчики вынесены в отдельные элементы интерфейса.
- Обновлена стратегия Service Worker: при смене версии оболочка кешируется отдельно, старый кеш удаляется после активации новой версии.

## Среда и совместимость

- Windows 11, Node.js 24.18.1, npm 11.16.0.
- Capacitor 7.6.10, Gradle Wrapper 8.11.1, Android SDK Platform 35 и Build Tools 35.0.0.
- Для Android-модуля Capacitor требуется Java 21. Сборка выполнена с JBR 25 из Android Studio; системный JAVA_HOME указывал на JDK 17 и для этой версии Capacitor не подошёл.
- В Android Studio добавлен параметр android.overridePathCheck=true, потому что рабочий путь Windows содержит кириллицу.
- В методичке описана установка Node.js на Debian; работа выполнена в доступном Windows-окружении с теми же Node/npm-инструментами.

## Результаты сборки

Выполнены npm install, npx cap add android, npm run android:sync и чистая команда .\gradlew.bat --no-daemon clean assembleDebug --console=plain.

**Результат:** BUILD SUCCESSFUL. APK: android/app/build/outputs/apk/debug/app-debug.apk. Установленный пакет имеет minSdk 23 и targetSdk 35.

## Проверка

### Браузерная PWA

- Service Worker зарегистрирован и активировал офлайн-кеш.
- Добавлены две задачи; одна отмечена выполненной.
- Фильтр «Выполненные» показывает завершённую запись.

- После смены версии Service Worker обновил оболочку, а затем новая версия страницы также открылась без запущенного сервера.

### Android через Capacitor

- APK установлен на эмулятор Pixel 6 с API 35.
- Проверены добавление задачи, переключение выполнения, фильтрация и удаление.

- При включённом авиарежиме задача была добавлена локально; затем приложение было перезапущено без сети, и обе задачи остались на экране.

## Вывод

Создано адаптивное PWA-приложение и Android APK на Capacitor. Браузерная версия открывается после предварительного кеширования без локального сервера, Android-версия работает автономно благодаря локальным веб-ресурсам в APK, а задачи сохраняются на устройстве.

Проверено хранение в localStorage; данные не синхронизируются между PWA и Android-версией. В качестве дополнительного задания подготовлено сравнение подходов. Push-уведомления, синхронизация с удалённым сервером и камера не добавлены: для них в материалах не предоставлены сервер Push/VAPID, backend синхронизации или требования к разрешениям камеры.
