# PWA To-Do List — прогрессивное веб-приложение

## Описание

Адаптивный список задач на HTML, CSS и JavaScript. Приложение сохраняет записи в localStorage, устанавливает PWA Service Worker для кеширования оболочки и собирается в Android-приложение с Capacitor.

Исходная структура и модель Model/View/Controller основаны на шаблоне из методички. Исправлены ошибки шаблона в callback-обработчиках и обновлении счётчика задач.

## Возможности

- добавление, завершение и удаление задач;
- фильтры «Все», «Активные» и «Выполненные»;
- сохранение списка между перезапусками;
- Web App Manifest с иконками 192×192 и 512×512;
- кеширование HTML, CSS, JavaScript, манифеста и иконок;
- обновление кеша по версии Service Worker и удаление старых версий;
- локальный запуск PWA и Android-сборка через Capacitor;
- экран сообщает о готовности офлайн-кеша после активации Service Worker.

Данные хранятся локально отдельно для браузерной и Android-версии. Синхронизация между устройствами и сервером не настроена.

## Технологии

- HTML5, CSS3, JavaScript ES2020;
- Service Worker, Cache API, Web App Manifest;
- localStorage;
- Node.js и npm;
- Capacitor 7.6.10;
- Android SDK 35.

## Запуск PWA

Требуется Node.js 20 или новее. В корне этой папки выполните:

1. npm install
2. npm start
3. Откройте http://localhost:4173.

Service Worker требует безопасный контекст: HTTPS или localhost. Для проверки офлайн-режима откройте приложение один раз, затем остановите сервер и перезагрузите вкладку. Список задач сохраняется в локальном хранилище браузера.

## Сборка Android APK

1. Установите зависимости: npm install.
2. Синхронизируйте веб-ресурсы: npm run android:sync.
3. В папке android выполните .\gradlew.bat clean assembleDebug.
4. APK появится в android/app/build/outputs/apk/debug/app-debug.apk.

Capacitor 7.6.10 использует Java 21 для Android-модуля. Для сборки подойдёт JDK 21 или новее; в этом окружении сборка выполнена через JBR 25 из Android Studio. Для каталога с кириллическим путём добавлен android.overridePathCheck=true в android/gradle.properties.
